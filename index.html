Fast, and otherwise invisible

Extract here does the right thing
If the archive holds a single folder, you get that folder. If it holds loose files, they go into a new folder named after the archive. No more desktops full of stray files.
Never overwrites your files
Extracting twice gives you a second folder, never a merge. Archives can't write outside the folder you extract into.
Stays out of the way
No tray icon, no update pop-ups, no ads, no telemetry. A successful extraction shows no window at all; the folder just appears.
Asks only when it has to
A password-protected archive gets one small password box. Type it wrong and the box stays open so you can try again.

Install on Windows

  1. Unblock the download

    Right-click tear-windows-x64.zip, choose Properties, tick Unblock at the bottom and click OK. Tear isn't code-signed yet, so Windows marks it as untrusted.

  2. Extract the zip

    Right-click it again and choose Extract All.

  3. Run Install.cmd

    Double-click Install.cmd in the extracted folder. If Windows shows Windows protected your PC, click More info, then Run anyway. It installs for your account only and needs no administrator rights.

  4. Right-click any archive

    Choose Tear, then Extract here. On Windows 11 it's under Show more options, or press Shift+F10.

To remove Tear, double-click Uninstall.cmd. The full guide, including terminal commands, is in INSTALL.md.
